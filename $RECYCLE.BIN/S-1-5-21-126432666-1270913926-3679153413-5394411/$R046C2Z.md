# Rotation of Client Secrets:

Before the client secret expires it needs to be renewed.

**Responsibility - The customer's Azure administrator should generate the Client Secret & to be shared with the Siemens CApS team for further configurations.**

Steps to generate a new Client Secret: 

- In the application page, go to Certificates & secrets on the left menu.
- Under Client Secrets click New client secret
- Provide a description (e.g., "MyApp Secret").
- For Expires, select the maximum validity period available (usually 24 months or Custom if allowed).
- Click Add.

![alt text](Client_Secret.png)

Important: Copy the generated secret value immediately — it won’t be shown again.

**Once the Client Secret is generated, the Customer Azure Admin Team is responsible for securely sharing the Client Secret with the Siemens CApS Team to be updated in the Hashicorp vault.**
