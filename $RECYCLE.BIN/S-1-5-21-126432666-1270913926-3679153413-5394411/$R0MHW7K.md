## Validations for Teamcenter X Premium

The following sections of the cookbook outlines the validations process for Teamcenter X Premium.

To validate the installation of Simulation features in Teamcenter X Premium:
1.	Login to Active Workspace as a user with a role "Analyst".
2.	Click on the user profile and validate that the role is "Analyst" and the Workspace is "Analyst".

    ![Validate Role](./Logged_Analyst.png)

3.	In the "Actions" tile click on the "Create Simulation".

    ![Create Simulation Tile](./Create_Simulation_Tile.png)

4.	In the "Create Simulation" Panel, in the "Type" dropdown select the type "CAE 1D Model".

    ![Create 1D Model](./Create_1DModel.png)

5.	Fill in the required details and click on the "Create" button to create a "CAE 1D Model"

    ![Create 1D Model](./Create_1DModel_Cre.png)

6.	Verify that the object is created in the Home folder without any errors.

    ![1D Model Created](./Model_created.png)
