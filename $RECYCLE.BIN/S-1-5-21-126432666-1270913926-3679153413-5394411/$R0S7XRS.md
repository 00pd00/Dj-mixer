## Installed Product Validation Steps Instructions

Steps to Login to Tcx From Rhapsody Connector:  
In Rhapsody connector select Log in Button  
![Image](./image_6.png)

This will open login dialog with TcX server(s) showing up in the drop-down box  
Select one of the TcX instances and click OK, user will be directed to log in Page  
![Image](./image_7.png)

User can provide details to complete log in.  
Login should be successful, a popup mentioning that the user is “now logged in” will be displayed to the user.

Export a model to Teamcenter  
In the Rhapsody application, the user can create a new project.  
Select the project model and choose the export option or use the "Right Mouse Button -> Teamcenter -> Export Model" command to export the model.  
Once the project model has been exported to Teamcenter, the project model and its exported elements will be suffixed with the Item ID & Revision ID.  
Select the exported project model revision > Right-click > Teamcenter > Open in Active Workspace to view the exported model in Active Workspace.
