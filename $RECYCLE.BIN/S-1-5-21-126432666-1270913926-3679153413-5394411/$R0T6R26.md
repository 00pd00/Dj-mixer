# Maunal File Shares AdHoc Backup

The primary purpose of this documentation is to instruct users on the process of manually backing up their Azure File Shares within the Azure portal with customized retention policies.

**Important Notes**
- Repeat this process for every File Share in your environment
- Document the date and time of each ad-hoc backup
- This information will be crucial when aligning with other backup components during restoration

### Steps to Create Ad-Hoc Backup

1. **Access Azure Portal**

    - Login to Azure Portal using your SPLM credentials
    - Locate the resource group: `tcx-tenant-<tenant-id>-<env-type>-rg`.
    - Find the File Shares Storage Account: `tcxt<tenant-id><env-id>fsa<first-3-char-of-subscription-id>`.
    - Locate and select your storage account

        ![alt text](image442.png)
    - Navigate to "Data storage" section, choose **File Shares** and select any of the file share to initiate the backup

        ![alt text](image443.png)


2. **Initialize Backup**

    - Navigate to "Operations" section and select **Backup**

        ![alt text](image444.png)

    - Click on **Backup now** Option

        ![alt text](image445.png)

3. **Configure Backup Settings**

    - Set the retention period according to your needs and click "ok"

        ![alt text](image446.png)

4. **Monitor Backup Progress**

    - Track the backup progress by clicking **View jobs**

        ![alt text](image447.png)

        ![alt text](image448.png)        

5. **Verify Backup Completion**
    
    - Once complete, the backup will be listed in the File Shares backup section

        ![alt text](image449.png)
