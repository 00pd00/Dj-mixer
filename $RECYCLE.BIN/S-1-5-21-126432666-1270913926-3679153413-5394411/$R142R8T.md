## Build-infra Failed: SQL MI Already Exists

**Note:** This workaround is applicable only for new deployments of TCX on Azure. Do not perform these steps for existing tenant.

**Issue Description**:

Build-infra stage failed while terraform is trying to create a SQL Managed Instance (SQL MI) that already exists in the Azure environment.

![Image](./image_azure_sqlmi_already_exist.png)
**Work Around:**  

1. Go to Azure Portal.  
2. Navigate to the Tenant Resource Group.  
3. Find and delete the existing SQL Managed Instance.  
![Image](./image_sqlmi_delete.png)  
4. Wait for the deletion to complete. This process may take up to 30 minutes depending on the size and configuration of the SQL Managed Instance.  
5. Validate that the deletion is complete by refreshing the resource group view in Azure Portal and ensuring the SQL Managed Instance no longer appears in the list of resources.  
6. Retry the job from the GitLab UI by navigating to the pipeline associated with the failed build-infra stage and clicking the retry button.
