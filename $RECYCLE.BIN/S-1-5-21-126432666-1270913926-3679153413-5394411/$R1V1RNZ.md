### Information

| Feature            | Details                                                                                                                |
|--------------------|------------------------------------------------------------------------------------------------------------------------|
| **Product IDs**    | Existing Easy Plan product IDs **TCM055021-XT** or **TCM055022-XT** are applicable for this add-on feature.<br/>Applicable PLM for Machine Builder product IDs are **TC032025-XT** or **TC032027-XT**. |
| **Teamcenter X**   | Teamcenter 2506.0002 and higher                                                                                                   |

## Pre-deployment

If **Easy Plan** is installed together with **PLM for Machine Builders**, the Easy Plan for Machine Builders feature will be installed automatically.

## Post-deployment

Create users under the selected roles to perform the basic sanity.

![User Roles](./image_1.png)

Login with user credentials to check the Machine Builders dashboard.

![Dashboard](./image_2.png)

Click on the NEW WORK PACKAGE command to use Easy Plan.
