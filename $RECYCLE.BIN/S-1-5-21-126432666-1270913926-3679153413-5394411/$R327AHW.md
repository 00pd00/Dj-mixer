## Day 0 Admin (infodba) Password Update

In previous versions of TcX (process-based), the `infodba` password had to be changed after the initial deployment. This change was required because Teamcenter initially deploys with a well-known password for the `infodba` user. That password must be changed to a hardened password value.

With TcX container deployments, the Admin password is auto-generated by the deploy automation pipeline and uses a hardened value. The hardened admin password is stored in HCVault by the deploy automation pipeline and later used by Teamcenter. New deployments of containerized TcX no longer require a password change immediately after the deployment completes.
