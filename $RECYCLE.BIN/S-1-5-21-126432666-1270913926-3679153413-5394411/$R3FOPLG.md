## Cloud Scheduler validation

Once deployment is successful, verify that the Cloud Scheduler has been set up correctly by executing the following steps:
1. In a browser, log in to AWC with the `TcXAdminUser` account.
2. Open another tab and enter the verification URL - `https://[tenant-subdomain].cloud.teamcenter.com/awc/tc/micro/txp/verify/config/cloudscheduler`.
3. Verify that the page displays server version information.
