# Upgrade path from TCX 2506 with DRV installed to TCX 2512

Follow this guide to upgrade TCX 2506 with DRV installed to latest TCX 2512 or highter version

## Rerun tcx pipeline with the PID and upgrade kit_file
The Caps user should rerun the tcx pipeline with PID: `TC20736-XT` and upgrade kit_file. Ensure the required configurations were included, refer to [Prepare the required configurations](../010_Pre-Deployment/000_Pre-Deployment.md#prepare-the-required-configurations)
