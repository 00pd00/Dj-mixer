# Day N Operations

This section lists the typical operations performed on an existing deployment. These steps are not mandatory to be followed, but can be performed based on need:

- Changing the password for admin users like infodba and tcxadmin on a ad-hoc basis
- Changing configuration parameters and/or preferences
- Build AW client artifacts (awbuild)
- LDAP configuration for additional admin users to be added (optional)
- Configure Admin License Server for Teamcenter X operating users
- Indexing after a data load operation
- Adding additional modules

The following sub-sections provide instructions on how to perform these operations.

In general, if an admin utility or a script needs to be executed, it should be be run using tcc command as per the steps specified in section [Executing Teamcenter ITK Utilities in a containerized environment](Executing%20Teamcenter%20ITK%20Utilities#executing-teamcenter-itk-utilities-in-a-containerized-environment) below.
