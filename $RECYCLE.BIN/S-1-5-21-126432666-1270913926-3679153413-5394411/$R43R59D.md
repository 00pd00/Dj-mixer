## Test Case 3: Check PAX Items  

Ensure PAX items are in the database.  
1. Login to the TcX environment through AW.  
2. Select workspace **Author**.  
3. Open **Advanced Search** and select **Item Revision...**.  
4. Click **Clear All**.  
5. Type `*pax*` in the **Item ID** field.  
6. Click **Search**.  
7. Ensure that those 3 item revisions below are found.  
- nx_cmm_pax_files
- nx2512_cam_pax_file
- nx2512_am_pax_file

## Test Case 5: Check Resources and Activities in Part Manufacturing Tab  

Ensure resources and activities are displayed properly in "Part Manufacturing" tab.  

**Pre-requisites:**  
- Download and install a compatible NX version on your local machine.  
  
**Compatibility Matrix Table:**  
| TcX       | NX       |
|-----------|----------|
| TcX 2512  | NX 2512  |
| TcX 2606  | NX 2606  |
| TcX 2612  | NX 2612  |
| ...       | ...      |

- Download and install:  
  - **Teamcenter_Connection_Manager.exe**  
  - **Teamcenter_Integration_for_NX.exe**  
  - Select the correct version that belongs to this TcX version from [`this download location`](https://artifacts.industrysoftware.automation.siemens.com/ui/native/generic-local/com/siemens/tcx/client_install/dev_builds/installers/)  
  - For example:  
    - Select the latest version folder in tc2512 for TcX 2512  
    - Select the latest version folder in tc2606 for TcX 2606  
    - Select the latest version folder in tc2612 for TcX 2612  
    - ...
- Use the correct property values for the TCX environment.  
- You can also use the **Teamcenter_Integration_for_NX.zip** kit that is being sent to the customer. It contains the two executables and also the properties file.  

1. Start NX in **Managed Mode** by clicking the **NX_managed** icon on the desktop.  
2. Go to **File → New Item**.  
3. Select the **Model** tab.  
4. Choose **Model** and assign **ID**, **Revision**, and **Name**.  
   ![Screenshot](Image4.png)  
5. Model a Block.  
   ![Screenshot](Image5.png)  
6. Click **Save**.  
   ![Screenshot](Image6.png)  
7. Go to **File → New Item** again.  
8. Select the **Manufacturing** tab.  
9. Choose **Generic Setup ASCII** and assign **ID**, **Revision**, and **Name**.  
   ![Screenshot](Image7.png)  
10. Open **Operation Navigator** and select **Machine Tool View**.  
    ![Screenshot](Image8.png)  
11. Create a new **End-Mill** tool.  
    ![Screenshot](Image9.png) ![Screenshot](Image10.png)  
12. Define **Workpiece** and **Blank Geometry**.  
13. Create a new **FLOOR_FACING** CAM operation and generate it.  
    ![Screenshot](Image11.png) ![Screenshot](Image12.png)  
14. Postprocess.  
    ![Screenshot](Image13.png) ![Screenshot](Image14.png) ![Screenshot](Image15.png)  
15. Generate **Shop Documentation**.  
    ![Screenshot](Image16.png)  
16. Click **Save**.  
    ![Screenshot](Image17.png)  
17. Login to the TcX environment through AW.  
18. Open the **CAM Setup** created in step #9.  
19. Go to the **Part Manufacturing** tab.  
    ![Screenshot](Image18NEW.png)  
20. Verify:  
    - **Resources Table**: "MILL" METool and Model METarget (created in step #4) are displayed.  
    - **Activities Table**: "NX CAM program group" and "FLOOR_FACING" operation are displayed.  
21. Select **NX CAM program group** in the **Activities** table.  
    ![Screenshot](Image19NEW.png)  
22. Verify in **Files Table** in the **Attachements** tab: `UGCAMCLSF`, `UGCAMPTP` & `UGCAMShopDoc` are listed.  
23. Verify that the NC Program is displayed in **Preview**.  
24. Select **FLOOR_FACING** in the **Activities** table.  
    ![Screenshot](Image20NEW.png)  
25. Verify:  
    - **Duration** has a value.  
    - "MILL" is displayed in **Assigned Ressources** table in the **Overview** tab.
