## Deactivate user

Deactivated user doesn't consume author license. To deactivate a user, follow these steps:

- Login to AWC using tcxadmin user and switch to Active Admin workspace.
- Go to 'People' tile, and go to Users tab.
- Click on the user and Edit it
- Change value for 'Status' property from '0' to '1' as show below.

  ![Image](./image_355.png)


- Save changes
