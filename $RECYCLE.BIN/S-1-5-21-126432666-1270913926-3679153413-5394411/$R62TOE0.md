# Introduction

Teamcenter Shape Search Product ID    - TC010261-XT

## Teamcenter Shape Search

Teamcenter Shape Search allows the user to search for objects using the Geolus application based on the shape of the object. 

## Dependency

While the Shape Search application can be installed during TcX Deploy. For Shape Search to run and work properly it requires Geolus to be properly installed and data indexed into the Geolus Database.

## Time for Manual Steps

Time required for manual steps is estimated to take 20 minutes.
In the event of a DC execute post manual steps being run. Only the identityservice.xml file manual steps need to be run. The preference gerneration steps and token generation steps are only required during first time install.
