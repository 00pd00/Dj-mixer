## deployutils failure with import_default_rule_data

If the software package acp0awcontrolplan  (TC050425-XT) is deployed into an existing environment, deployutils fails while executing the import_default_rule_data utility with below error:

 Function: createNamingConventionsIfNotExists Error code: 128027 Error message: The key "key_acp0_characteristics_type_attributive" could not be found in the TextServer text resource files.

Error 128027 Error message: The key "key_acp0_characteristics_type_attributive" could not be found in the TextServer text resource files. occurred while importing default naming convention.

 **Workaround:**

- Modify tc-deployutils-env config map in helm_charts/deploy/tc_deployutils/templates/configmap.yaml file in the tenant git repo to disable the usage of textsrv shared memory during the deployment

    TC_USE_TEXTSRV_SHARED_MEMORY: “false”

- Synchronize the deploy app in ArgoCD using Sync command to update the tc-deployutils-env configmap in the tenant namespace in XCR Kubernetes cluster

- Restart the deployutils job . For more details, refer [Troubleshooting - Restarting the deployUtils Job](260_Restart%20deployutils%20if%20post%20deploy%20fails.md)
