#### Validation for Rotated Password

Run validation use cases intended for the specific password update. 

Here are a few validation scenarios provided for reference.
​​
| Sr. No | User(s) who's password is rotated | Validation |
|--------|-----------------------------------|------------|
| 1 | Infodba | Verify Daemons & indexer pods are up & running |
| 2 | tcxadmin | Successful AWC login with tcxadmin user Email ID registered in SAMAuth. This is the email provided to TcXAdminEmail customer input while launching Ansible playbook |
