# Backup, Restore and Destroy

**Responsibility: CApS Team**

The Microsoft Office Online server does not store any user data, thus there are not any special instructions for backing up and restoring the tenant when Teamcenter Office Online is deployed.

Simply follow the same steps used to backup and restore other tenants with Teamcenter.

Additionally, to destroy a tenant where this has been deployed, simply run the destroy pipeline for the tenant in tcx-pipeline-tenant.
