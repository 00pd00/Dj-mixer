# Manual VM Restores

## Documentation Overview
This documentation provides a step-by-step guide for restoring an Azure Virtual Machine (VM) from a backup using the Azure Portal. It includes detailed instructions and placeholders for visual aids to assist users in the process.

### Steps to Restore a VM

1. **Configuration Variables**:
  - `CONTAINER_NAME`: Specifies the name of the backup container associated with the VM.
  - `ITEM_NAME`: Specifies the name of the backup item (typically the VM name).
  - `RESOURCE_GROUP`: Specifies the Azure resource group where the VM and backup resources are located.
  - `VAULT_NAME`: Specifies the name of the Recovery Services vault used for backups.
  - `STORAGE_ACCOUNT`: Specifies the name of the storage account where the restored disks will be stored.
  - `BACKUP_MANAGEMENT_TYPE`: Specifies the type of backup management (e.g., `AzureIaasVM` for Azure VMs).

```bash
CONTAINER_NAME="tcx-tenant-<tenant-id>-<env-type>-CorpServer-vm" or "tcx-tenant-<tenant-id>-<env-type>-WindowsServer1-vm"
ITEM_NAME="tcx-tenant-<tenant-id>-<env-type>-CorpServer-vm" or "tcx-tenant-<tenant-id>-<env-type>-WindowsServer1-vm"
RESOURCE_GROUP="tcx-tenant-<tenant-id>-<env-type>-rg"
VAULT_NAME="tcx-tenant-<tenant-id>-<env-type>-rsvault"
STORAGE_ACCOUNT="tcxt<tenant-id><env-type>rsa<initial-3-digits-of-subscription-id>"
BACKUP_MANAGEMENT_TYPE="AzureIaasVM"
```
**Note**: Replace the `tenant-id` and `env-type` in above commands.

2. **Fetching Recovery Points**:
  - The script retrieves a list of available recovery points for the specified VM.
  - The output includes the recovery point time, expiry time, and recovery point ID.
  - Command: 
    ```bash
    echo "Fetching recovery points..."
    echo "recoveryPointTime   expiryTime   recoveryPointID"
    az backup recoverypoint list \
     --container-name "$CONTAINER_NAME" \
     --item-name "$ITEM_NAME" \
     --resource-group "$RESOURCE_GROUP" \
     --vault-name "$VAULT_NAME" \
     --backup-management-type "$BACKUP_MANAGEMENT_TYPE" \
     --query "[].{ time:properties.recoveryPointTime, expiryTime:properties.recoveryPointProperties.expiryTime, id:name}" \
     -o tsv
    ```

![Image](./image433.png)

3. **Triggering Restore Job**:
- The recovery point ID (`RP_NAME`) must be specified to initiate the restore.
- **Check Recovery Point Date**:
  - Review the recovery point date and expiry date from the output of the previous command.
  - Identify the desired recovery point ID based on the date and time you want to restore.
  - Use the selected recovery point ID in the `RP_NAME` variable for the restore operation.
  - The restored disks will be stored in the specified storage account.
  - Command:
    ```bash
    RP_NAME="#####"
    az backup restore restore-disks \
     --container-name "$CONTAINER_NAME" \
     --item-name "$ITEM_NAME" \
     --resource-group "$RESOURCE_GROUP" \
     --rp-name "$RP_NAME" \
     --storage-account "$STORAGE_ACCOUNT" \
     --vault-name "$VAULT_NAME" \
     --restore-mode OriginalLocation
    ```

**Note**: Replace the placeholder `RP_NAME` with the actual recovery point ID you want to use for the restore operation.

### Monitor Restore Job Progress
- The restore job will be triggered.
- Locate the resource group: `tcx-tenant-<tenant-id>-<env-type>-rg`.
- Select the specific Virtual Machine (VM) you just triggered Restore operation.
- Go to the **Backup** under **Backup + disaster recovery** section.
- Track the progress by clicking **View Jobs**.
