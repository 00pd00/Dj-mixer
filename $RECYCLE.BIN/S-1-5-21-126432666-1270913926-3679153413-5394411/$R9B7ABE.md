
#### Vault Password Update

1. Log in to the Vault.
2. Select the tenant namespace.
    ![Image](./image_364.png)
3. Navigate to the appropriate vault secret path to change the password.
    ![Image](./image_365_new.png)
    ![Image](./image_367.png)
4. Edit the password and click **Save**. Your intended password is updated in the vault. Follow the remaining steps to update all TC references.
