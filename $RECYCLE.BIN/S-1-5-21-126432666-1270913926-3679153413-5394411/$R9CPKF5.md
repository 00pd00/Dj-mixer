# Overview

Before proceeding, please review the following:

- **Intended Use:** This guide is for upgrading the TcX product tier (TcX Advanced to TcX Premium) while maintaining the same TcX Version.
- **Scope Limitations:** Installation of additional modules or configuration updates is not supported or recommended.

---

## Prerequisites

Ensure you have the following:

- Access to [Ansible Tower](https://ansible-tcx-prod.plmcloudsolutions.com/)
- Access to [Xcelerator Admin Console](https://cloud.sw.siemens.com/)
