# TcX Standard and TcX Advanced Translators Guide

**Applicable Product IDs:** TC7100, TC7101

This document provides a comprehensive list of translators available for TcX Standard and TcX Advanced, along with their installation details and software prerequisites. Please follow the instructions provided in each section to ensure all necessary requirements are met before use.

## Supported Translators

| Translator Name                                   | TcX Standard | TcX Advanced | Installed by Default | Software Prerequisites      |
|---------------------------------------------------|--------------|--------------|---------------------|-----------------------------|
| Async Service Translator                          | Yes          | Yes          | Yes                 | -                           |
| NX Direct Translator                              | Yes          | Yes          | Yes                 | NX                          |
| Preview Service Translator                        | Yes          | Yes          | Yes                 | MS Office Tc Visualization  |
| Render Management Translator                      | Yes          | Yes          | Yes                 | MS Office Tc Visualization  |
| Requirements Management Compare Contents Translator| Yes          | Yes          | Yes                 | MS Word                     |
| Requirements Management HTML to Word Translator    | Yes          | Yes          | Yes                 | -                           |
| Requirements Management Perform Operations        | Yes          | Yes          | Yes                 | MS Word                     |
| Requirements Management Word to HTML Translator   | Yes          | Yes          | Yes                 | -                           |
| SolidEdge to JT Translator                        | Yes          | Yes          | No                  | Solid Edge                  |

Before using any translator, make sure the required prerequisites are installed. Refer to the instructions below for setup guidance.

>__Note:__
> For __TcX Premium__, first check which translators are requested by customer to be onboarded. Accordingly follow the steps for configuring the respective translator.

## 1. Async Service Translator Setup

No additional configuration is required for the Async Service Translator. You can begin using this translator immediately.
