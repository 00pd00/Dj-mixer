# Importing Pre-Packaged Classification Hierarchy in TcX Advanced

**Applicable Product IDs:** TC7101

> **Note:** Ensure you complete the Dispatcher installation before proceeding with the steps below.

## Step-by-Step Procedure

1. Import the pre-packaged classification hierarchy into TcX Advanced by following the guidance in the [Import Pre-Packaged Classification Hierarchy for ECAD, MCAD, and Routing Data for Basic Classification](https://internal.docs.sw.siemens.com/en-US/doc/282219420/PL20250520748650994.basic_class_deploy/xid2252446) documentation.

2. Once you have imported the classification hierarchy, index the classification data according to the instructions in the [About Indexing Classification Data](https://internal.docs.sw.siemens.com/en-US/doc/282219420/PL20250520748650994.class_aw/xid1755823) documentation.
