  - **1.6** Formal documented policies and requirements must be implemented to facilitate governing the installation of
software/firmware by network administrators.
    - **1.6.1** Technical controls must be implemented to restrict the installation of software/firmware on
operational systems.
  - **1.7** Standards must be established to guide personnel on the types of software installations that are permitted and
what types of installations are prohibited on information resources.
    - **1.7.1** Requirements must be implemented to govern the installation of software by personnel and establish
the types of software installations permitted and prohibited on information resources.
    - **1.7.2** Applications or specific application versions no longer supported by the vendor or whose
development has been discontinued must not be used and be removed from IT systems.
  - **1.8** Formal standards must be implemented for the hardening of SISW information resources, inclusive of
configuration management tools to detect and report configuration nonconformities for automated or manual
remediation.
    - **1.8.1** Endpoints must be configured, hardened, monitored, and maintained based on established security
requirements, including but not limited to installation of only approved images during initial configuration,
restrictions on local administrator privileges, periodic patch updates, and operating system hardening to
provide only necessary ports, services and protocols.
    - **1.8.2** All mobile devices must be deployed with hardening standards, in line with documented procedures.
  - **1.9** Processes must be implemented for monitoring information resources.
    - **1.9.1** Network activities must be logged and monitored, considering the requirements established in SISW's
policy on security logging and monitoring.
    - **1.9.2** Connections from the SISW network to systems external to the SISW network must be verified and
controlled.
  - **1.10** Administrative and technical controls must be implemented for information resource malware detection
and remediation.
    - **1.10.1** Access points into the SISW network from internal and external connections must be secured using
network protection and detection devices, including but not be limited to firewalls, routers, switches, intrusion
detection / prevention systems, and data loss prevention systems.
    - **1.10.2** Administrative and technical controls must be implemented for information resource malware
detection and remediation.
    - **1.10.3** Web filtering rules must be established and kept current to minimize exposure to known or suspected
malicious online resources.
    - **1.10.4** Host-based protection mechanisms (e.g. firewalls) must be configured for endpoints.
SISW Saas Physical Security Policy requirements
  - **1.1** Facilities department is responsible for assessing Siemens's physical locations and applying physical security
measures and adjusting those measures on an ongoing basis.
    - **1.1.1** SISW personnel are not permitted to adjust or circumvent physical security mechanisms (e.g., card
readers, cameras, etc.), without written approval from Facilities.
    - **1.1.2** Questions, concerns, or change requests regarding physical security measures must be directed to
Siemens' Facilities team.
