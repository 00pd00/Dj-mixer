# Introduction and Scope

The goal of this cookbook is to provide instruction on how to deploy containerized TcX into an XCR Kubernetes cluster on cloud platforms (e.g., Amazon Web Services [AWS], Microsoft Azure).  The scope will include TcX cell setup, and other prerequisites before a deployment of containerized TcX can occur. 

The intended audience is anyone that wants to deploy and maintain containerized TcX using TcX Automation.
