## Generate Secrets Vault token

### Install Vault CLI (One-Time Activity)

Navigate to the Windows section and download the Vault CLI from [HashiCorp Vault Downloads](https://developer.hashicorp.com/vault/downloads). Ensure that the `vault.exe` path is added to the `PATH` environment variable.

### Assume Admin Access Role

`aws sts assume-role --role-arn <Admin Access Role> --role-session-name secrets-vault `

### Assume AWS Vault IAM Role

```
set AWS_ACCESS_KEY_ID= Access key got from above step [Assume Admin Access Role]

set AWS_SECRET_ACCESS_KEY= Secret Access key got from above step [Assume Admin Access Role]

set AWS_SESSION_TOKEN= Session Token got from above step [Assume Admin Access Role] 

aws sts assume-role --role-arn <AWS Vault IAM Role> --role-session-name secrets-vault
```

### Generate Vault Token

Note: The placeholders below are generated by running the command mentioned in above section **Assume AWS Vault IAM Role**:

- `AWS_ACCESS_KEY_ID=<Access key obtained from the command>`
- `AWS_SECRET_ACCESS_KEY=<Secret Access key obtained from the command>`
- `AWS_SESSION_TOKEN=<Session Token obtained from the command>`

```
set VAULT_ADDR=<VaultEndpoint> 
set VAULT_NAMESPACE=<Parent Namespace>  
C:\apps\vault.exe login -method=aws -path=< Auth Path > header_value=<VaultEndpoint> role=<Vault Backend Role > aws_access_key_id=<AWS_ACCESS_KEY_ID> aws_secret_access_key=<AWS_SECRET_ACCESS_KEY> aws_security_token=<AWS_SESSION_TOKEN>
```
