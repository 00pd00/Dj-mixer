## Pre-requisites

Rhapsody Connector for Teamcenter v2412 requires a Java Runtime Environment (JRE) version 17, which is included with the installer, or any compatible external JRE (recommended: Zulu 17).

**Teamcenter Client components:**
- Teamcenter Client Communication System (TCCS)
- Teamcenter Security Services Session Agent

> **Note:** No separate license is required for Teamcenter X integration with Rhapsody as it is seeded in Teamcenter license itself.
