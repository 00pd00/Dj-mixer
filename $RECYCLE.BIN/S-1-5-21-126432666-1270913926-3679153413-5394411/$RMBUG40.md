### Generate the dedicated Service User and Static Access Keys for Digital Reality Viewer Application

This guide will help you add a dedicated Service User—an automated, non-human account—so your Digital Reality Viewer Application within Teamcenter X environment can securely interact with DSS and XRS services. 



### Step-by-Step Instructions

#### Generate the Service User and Access Keys

1. **Launch the SetupServiceUser API**
   - This API manages the creation of the Service User and its access keys.

2. **Input Credentials**
   - Use the temporary access keys generated by invoking the ActAsRole API request on the customer SAM account:
     - **SAM Access Key**
     - **SAM Secret Access Key**

3. **Specify the Policy File**
   - The CLI command requires a JSON policy file name.
   - **Always use:** `TcXDRVServiceUserPolicy.json`


- **For tenant environments:**  
  
**Linux**
```
aws lambda invoke --region us-east-1 --function-name arn:aws:lambda:us-east-1:361500002652:function:tcx_cli:PRD --cli-binary-format raw-in-base64-out --payload '[["<SAM_ACCESS_KEY>","<SAM_SECRET_ACCESS_KEY>","us-east-1.sws.siemens.com"],["SetupServiceUser","<SAM_ACCOUNT_ID>","TcXDRVServiceUserPolicy","TcXDRVServiceUserPolicy.json","TcXDRVServiceUserGroup","TcXDRVServiceUser"]]' outputfile.txt
```
**Windows**
```
aws lambda invoke --region us-east-1 --function-name arn:aws:lambda:us-east-1:361500002652:function:tcx_cli:PRD --cli-binary-format raw-in-base64-out --payload "[[\"<SAM_ACCESS_KEY>\",\"<SAM_SECRET_ACCESS_KEY>\",\"us-east-1.sws.siemens.com\"],[\"SetupServiceUser\",\"<SAM_ACCOUNT_ID>\",\"TcXDRVServiceUserPolicy\",\"TcXDRVServiceUserPolicy.json\",\"TcXDRVServiceUserGroup\",\"TcXDRVServiceUser\"]]" outputfile.txt
```

If installed correct, it should return output like the following.
```json
{
  "userGUID" : "<USER_GUID>",
  "accessKey" : {
    "objectGUID" : "<OBJECT_GUID>",
    "secretAccessKey" : "<SECRET_ACCESS_KEY>"
  }
}
```

### Required Values for Tenant Stack Deployment

Please keep the highlighted values below handy. You will need them for tenant stack deployments.

##### Value Reference Table

| **Value to Copy**        | **Description**                                                                                                  | **Parameter in Customer Input JSON File**   |
|--------------------------|------------------------------------------------------------------------------------------------------------------|---------------------------------------------|
| **objectGUID**            | The account access key for the Metaverse Translater service user in the SAM Customer (tenant) account.                       | `MetaverseTranslatorAccesskey`                      |
| **secretAccessKey**       | The secret access key for the Metaverse Translater service user in the SAM Customer (tenant) account.                         | `MetaverseTranslatorSecretaccesskey`                |
