### Check Shape Sublocation exists

This assumes the following:
- **Shape Search application is installed**
- **Geolus is installed and setup**
- **Geolus Public Endpoint set for GeolusServer** 
- **Geolus Application Id set for geolusClientId** 
- **isGeolusService set to true** 


Navigate to the Search location via any avenue (global search, Saved search tile, Advanced search link). When in the Search location the ‘Shape’ sublocation should be listed.

![Search sublocations](SearchSubLocationList.png)


Selecting 'Shape' from the list should not cause errors and load the shape sublocation. Which consists of the Select Shape candidate panel and an empty list view.

![Shape Search Location](ShapeSearchSubLocation.png)
