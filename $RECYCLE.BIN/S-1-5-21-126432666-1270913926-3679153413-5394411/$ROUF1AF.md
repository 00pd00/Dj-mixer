### Set isGeolusService preference

**This preference should already be set to true during TcX environment deploy. However if it is not or needs to be check these are the steps to check and edit.**

Steps to set isGeolusService:

1. Login to tenants active workspace.

2. Select PREFERENCES as shown below:

![Active Workspace Preference Tile](PreferencesLocation.png)


3. Search for preference **isGeolusService**. Select the preference and from the right panel scroll down to VALUES section.

4. Edit the preference and set the value to **true**.

![Setting isGeolusService preference](SavingisGeolusServicePreference.png)

5. Save the preference
