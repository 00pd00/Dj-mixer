# Teamcenter X Essentials to Teamcenter X Standard/Advanced/Premium Data Migration Overview

## Migration Overview

This document outlines the data migration process from Teamcenter X Essentials to Teamcenter X Standard, Advanced, or Premium editions. Follow the provided sequence to ensure a smooth and reliable migration.

### Migration Sequence

The migration involves multiple components working together:
- **infodba**
- **Teamcenter X Essentials**
- **Teamcenter X Standard/Advanced/Premium**
- **File Management System (FMS)**
- **Volumes**
