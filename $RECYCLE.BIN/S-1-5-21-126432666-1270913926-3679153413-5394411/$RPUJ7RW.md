### Set geolusClientId preference

This assumes you already know the following from the Geolus install:
- **Geolus Application Id** 

Steps to set geolusClientId:

1. Login to tenants active workspace.

2. Select PREFERENCES as shown below:

![Active Workspace Preference Tile](PreferencesLocation.png)


3. Search for preference **geolusClientId**. Select the preference and from the right panel scroll down to VALUES section.

4. Edit the preference and set the value to the Geolus Id from SamAuth.

![Setting geolusClientId preference](SavingClientIdPreference.png)

5. Save the preference
