# Test Suites

This section contains comprehensive test suites for all TC SLM applications. Execute the appropriate test suite based on your deployed product.

## Available Test Suites

| Test Suite | Product ID | Product Name | Purpose |
|------------|------------|--------------|---------|
| [Service Engineering Tests](./TC032021_ServiceEngineering-tests.md) | TC032021-XT | Service Engineer | Test SBOM management and service BOM alignment |
| [Service Plan Tests](./TC032026_ServicePlan-tests.md) | TC032026-XT | Service Planner | Test service plan creation and management |
| [Service Events Tests](./TC032023_ServiceEvents-tests.md) | TC032023-XT | Service Asset Management | Test as-maintained structures and service events |
| [As-Built Tests](./TC031201-XT_AsBuilt-tests.md) | TC031201-XT | As Built Management | Test as-built structure creation |
| [SWI Tests](./TC032020-XT_SWI-tests.md) | TC032020-XT | Service Technician Access | Test service work instructions |

## Testing Guidelines

- Ensure proper role configuration before running tests
- Note the transaction times mentioned in each test
- Verify all prerequisites are met before execution
- Follow the step-by-step procedures exactly as documented
