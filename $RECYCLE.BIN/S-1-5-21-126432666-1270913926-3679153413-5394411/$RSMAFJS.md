# Prerequisite

- AIG foundation and SIM gateway is installed
- Dispatcher installed

# Deployment

- A fully provisioned TcX environment that includes following product:
    - TC10325-XT
    - TC030795-XT or TC030794-XT

- For installing AIG refer to the following guide.
  
  [Detailed AIG Installation Guide](https://mypolarion.industrysoftware.automation.siemens.com/polarion/#/project/Teamcenter/wiki/TCX%20Solution%20Install%20Documentation/AIG-cookbook-HybridMode)

- Access to both BGS and GS UI through CyberArk.
