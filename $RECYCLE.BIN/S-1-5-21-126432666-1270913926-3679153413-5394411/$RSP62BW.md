
#### Steps to create Teamcenter X Operating SAM Account

1. Identify the Teamcenter X operating SAM account owner. This Siemens Managed Service staff will be responsible for requesting and managing this account.
    a. Account Name:  A Siemens managed services organization name
    b. Account Owner: A Siemens managed services person
2. Fill out the PL PaaS account request form and send it to Ken Roger and Kunal K using this link  http://civ6w178:3000/DevConsole

    It is important to indicate that this account requires Application Developer access. This will allow this account to use Siemens-only PL PaaS services (such as access to SAMAuth Application Registration Console).
    Please indicate the region which this SAM Account is created (for example us-east-1 or euc1.eu)
    ![Image](./image_92.png)


3. Once created, verify if the account owner can login to this new SAM Account via SAM Console using WebKey credential.


Note: For environment creation for dev use also use SAM prod account.
