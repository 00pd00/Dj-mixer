# Microsoft Office Installation Guide

Follow these simple steps to install Microsoft Office on your computer.

## Prerequisites

- Download Microsoft Office from the official [Microsoft website](https://www.microsoft.com/).
- Ensure you have your product key ready for activation.

## Installation Steps

1. **Download the ISO File**  
   Download the Microsoft Office ISO file from the official Microsoft website.

2. **Mount the ISO File**  
   Right-click the downloaded ISO file and select **Mount**. This action opens a File Explorer window with the Office installation files.

3. **Run the Setup Program**  
   Inside the mounted directory, double-click `Setup.exe` to start the installation.

   ![Microsoft Office Setup](./image_169.png)

4. **Complete the Installation**  
   Wait while Microsoft Office installs. The installation may take a few minutes.

   ![Installation Progress](./image_170.png)

5. **Activate Microsoft Office**  
   After installation, open any Office application such as Word, PowerPoint, or Excel. When prompted, enter your product key to activate your software.
