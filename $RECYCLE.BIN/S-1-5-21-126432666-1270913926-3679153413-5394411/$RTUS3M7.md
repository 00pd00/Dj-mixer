### Set GeolusServer preference

This assumes you already know the following from the Geolus install:
- **Geolus Public Endpoint** 

Steps to set GeolusServer:

1. Login to tenants active workspace.

2. Select PREFERENCES as shown below:

![Active Workspace Preference Tile](PreferencesLocation.png)


3. Search for preference **GeolusServer**. Select the preference and from the right panel scroll down to VALUES section.

4. Edit the preference and set the value to the Geolus public endpoint.

![Setting GeolusServer preference](SavingGeolusServerPreference.png)

5. Save the preference
