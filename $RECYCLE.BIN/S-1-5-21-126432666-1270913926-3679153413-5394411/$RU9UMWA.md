# Teamcenter Integration for Power BI software: Introduction

- Available in TcX version 2512 and above (Incubation feature in 2512)
- Name: TcX Integration with Microsoft Power BI
- Product ID: TC20550-XT


Overview:
The TcX integration with Microsoft Power BI enables you to analyze and visualize data, information, and processes from within TcX using the industry-leading business intelligence platform. This integration empowers users to build dynamic, customizable reports and dashboards in Power BI, helping drive insights into PLM data such as BOMs, workflows, and process efficiency.


Key Features & Benefits:

- Seamless Data Export:
Push data from TcX directly into your Power BI workspace for detailed analysis.
- Support for Core TcX Constructs:
Analyze standard TcX objects including BOMs, Change Records, and Workflows.
- Security Compliance:
Enforces TcX access control policies based on the current logged-in user’s permissions.
- Data Mashups:
Combine TcX data with other sources in Power BI for comprehensive business insights.
