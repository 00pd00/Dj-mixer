# Publish a Design in Teamcenter-X

Open Capital Logic Designer application
Open “Quick Start Interactive” project in it
Go to “Workflow’ tab and from “Configuration Properties” dialogue give TC credentials as follows and press “Teamcenter” button.
![Image](./image_16.png)


Connect to Teamcenter-X using SSO login with SAM AUTH User details in default browser (chrome or Edge etc).
![Image](./image_17.png)


Select the Design Revision node as shown below after connection to Teamcenter-X (Import Quick Start Automotive Interactive Project)
![Image](./image_18.png)


Click RMB on Design node for Publish Action Or Select Publish via Capital Ribbon.
![Image](./image_19.png)


Once clicked on Publish, Publish Design Dialog will appear with Transcript related to action performed on server.
User will go thru details once publish is completed, it will give details like Project/Design already created or fetch etc.
![Image](./image_20.png)


Once Publish is completed, Invoke Teamcenter (embedded Active workspace Client) in Capital.
Press Spacebar – Type “Open”, This will open Teamcenter AWC & Press on Search afterward.
![Image](./image_21.png)


Switch to attachments tab from Overview Tab in AWC
User can check the PDF preview in Overview Tab and download dataset from embedded browser for further checks.
![Image](./image_22.png)
