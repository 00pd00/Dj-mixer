# Validation Steps for Active Assistant in Teamcenter X

**Applicable Product IDs:** TC7003-XT, TC7100, TC7101

Follow these steps to verify and utilize the Active Assistant feature in Active Workspace.

---

## How to Use Active Assistant

1. Log into Active Workspace using your WebKey credentials.
2. Locate the **Assistant** icon on the left side panel in Active Workspace.
3. Click the **Assistant** icon.  
   ![Click Assistant Icon](./image_242.png)
4. Pin the Assistant Panel for easy access.  
   ![Pin Assistant Panel](./image_243.png)
5. From the active assistant panel, select the **Newstuff folder**.
6. Open the **Newstuff folder**.  
   ![Open Newstuff Folder](./image_244.png)
7. To create a new item, click the **Add** button.  
   ![Click Add Button](./image_245.png)
8. Repeat step 7 several times to create multiple new items in the **Newstuff folder**.
9. On subsequent attempts to create a new item, you'll notice that recently used operations appear in the active assistant panel:  
   ![Recently Used Operations](./image_246.png)
10. Click **Add** directly from the active assistant panel to create additional items.  
    This feature allows Active Assistant to remember your recent actions, enabling quick navigation and efficient task completion.
