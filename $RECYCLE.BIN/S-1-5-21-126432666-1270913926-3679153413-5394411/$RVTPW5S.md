# Installation Notes for Easy Plan Optional Features

### 1. Easy Plan Classification Installation

- The **Easy Plan Classification** feature will be installed automatically as a dependent component when both **Classification (TC030401-XT)** and **Easy Plan** are installed.
- No separate action is required for installing Easy Plan Classification; it is included as part of the standard installation workflow when the above two features are selected.

### 2. Easy Plan Product Configurator Installation

- The **Easy Plan Product Configurator** feature will be installed automatically as a dependent component when both **Product Configurator (TC030719-XT or TC030720-XT)** and **Easy Plan** are installed.
- No separate action is required to install Easy Plan Product Configurator; it is included as part of the standard installation workflow when the above features are selected.
