### Change EFS Throughput settings for large files upload

> **Note:** These manual steps are applicable only to TcX releases below **2506.0006**.

1. Login to tenant AWS account 
2. Select EFS service
3. Click EFS (both one by one) so that more details are observed
4. Start Editing EFS, by clicking on Edit option 
5. Change the performance settings from Bursting to Elastic as seen in below image an save the settings ![Image](./image_372.png)
