## Classification Manager Admin preference setup for TCx

1. Login to the TCX environment through AW as a dba privileged user. 
2. Open preferences and search for the **CLS_is_presentation_hierarchy_active** preference.
3. Set the value of the preference from false to true
4. Open preferences and search for the **CLS_auto_sync_node_hierarchy** preference.
5. Set the value of the preference from false to true
