# Prerequisites

The following prerequisites must be completed before configuring Teamcenter Copilot for Structures:

1. Install, configure, and perform the object data and file content indexing. See [Indexing after a data load operation](../../Documentation/020_Operations/030_Day%20N%20Operations/090_Indexing%20after%20a%20data%20load%20operation.md).

2. Install and configure [Teamcenter AI Chat](../Teamcenter%20AI%20Chat/000_TC%20AI%20Introduction/010_Introduction.md).
